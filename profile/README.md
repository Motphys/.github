# Motphys

Motphys builds high-performance infrastructure for physics simulation, robot learning, and embodied AI.

**[Official Website](https://www.motphys.com/en/)**

Our open-source projects span the full development loop—from accurate, efficient simulation to scalable training and real-world deployment:

- **[MotrixSim](https://github.com/Motphys/motrixsim-docs)** — a high-performance physics simulation engine for multibody dynamics and robotics.
- **[MotrixLab](https://github.com/Motphys/MotrixLab)** — an open-source reinforcement learning framework for training and deploying robot policies.
- **[UniLab](https://github.com/Motphys/UniLab)** — infrastructure for robot learning across physics backends, compute platforms, and hardware.

We are building the tools that help researchers and engineers develop, evaluate, and deploy intelligent robots—from virtual worlds to the real world.
